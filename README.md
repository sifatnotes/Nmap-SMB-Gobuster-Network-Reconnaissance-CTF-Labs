## Learning Path

A practical sequence for this collection:

1. **Ping Probe: Find Hidden Host** — start with basic host discovery.
2. **Nmap Recon Mastery** — build core Nmap reconnaissance skills.
3. **Nmap Full Sweep** — expand scanning and enumeration practice.
4. **Prime Service Recon** — investigate discovered services.
5. **SMB Ghost Share** — introduce SMB-focused reconnaissance.
6. **SMB Share Sleuth 3** — continue SMB share enumeration.
7. **Writable Shares, Rooted Hosts** — examine writable-share scenarios.
8. **Plugin Hunt Prime** — move into application-focused discovery.
9. **Gobuster: Find Hidden Web Root** — practice web resource enumeration.
10. **Fog of Flags** — apply reconnaissance skills in a broader CTF setting.
11. **Fog: Root by the Book** — continue with a root-focused challenge.
12. **Crack the Fog** — consolidate enumeration and security-analysis skills.

## How to Use the Labs

* Open each challenge through its direct Learn SecByte URL.
* Begin with the stated objectives and enumerate systematically.
* For Nmap labs, document discovered hosts, ports, and services.
* For SMB labs, investigate available shares and access characteristics within the authorized environment.
* For web labs, examine application paths, plugins, and other discoverable resources.
* Record findings and reasoning throughout each challenge.
* Use only authorized lab environments for security testing.
* Treat each lab as a practical exercise in reconnaissance, enumeration, and defensive security awareness.
